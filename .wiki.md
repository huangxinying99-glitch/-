# Project Summary
This project is a dynamic web-based platformer game that immerses players in a vibrant, Kirby-inspired world filled with collectibles and challenges. Players navigate through various levels, collecting items and overcoming obstacles. Recent updates have optimized performance, introduced new animations, enhanced gameplay mechanics, and added immersive audio effects. The game features improved visuals with various decorations and assets, incorporating user feedback for an enhanced gameplay experience. Notable changes include the reintroduction of animated foreground flowers, the addition of new blue flowers alongside existing red and yellow flowers, and the implementation of a fullscreen mode that enhances the user experience by hiding the keyboard hints bar when active.

# Project Module Description
The project consists of the following functional modules:
- **Game Engine**: Manages core mechanics such as player movement, enemy behavior, and physics.
- **Graphics Rendering**: Handles the rendering of game elements with performance improvements.
- **User Interface**: Provides menus, score displays, and controls for user interaction, featuring updated icons and a simplified design.
- **Asset Management**: Organizes and loads images and sounds utilized in the game, including new decorative assets.
- **Level Design**: Configures level layouts, including obstacle placement and environmental features, enhanced with user-uploaded designs.

# Usage
To get started with the project, follow these steps:
1. Install dependencies:
   ```bash
   npm install
   ```
2. Build the project:
   ```bash
   npm run build
   ```
3. Run the project:
   ```bash
   npm start
   ```
